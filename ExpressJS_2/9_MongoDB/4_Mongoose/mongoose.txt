Official Definition:
Mongoose is an Object Data Modeling (ODM) library for MongoDB and Node.js. It provides a straightforward, schema-based solution to 
model application data. Mongoose includes built-in type casting, validation, query building, business logic hooks, and more, allowing 
developers to interact with MongoDB using an object-oriented approach instead of raw database commands.
Mongoose is a tool for Node.js that helps you work with MongoDB easily.
Instead of writing raw database commands, you can work with JavaScript objects.
It gives structure and rules to your data so everything stays organized.

Key Points:

ODM (Object Data Modeling) – maps JavaScript objects to MongoDB documents (Lets you turn JavaScript objects into 
MongoDB documents and vice versa).

Schema-based – lets you define the structure and data types for documents.

Validation – ensures data integrity before saving (Makes sure data is correct before saving it to the database).

Convenience methods – .find(), .save(), .updateOne(), etc.

1️⃣ Schema

Definition:
A schema is a blueprint or structure for documents in a MongoDB collection. It defines what fields each document should have, their data types, and optional validation rules.

Example in Mongoose:

const todoSchema = new mongoose.Schema({
    task: String,
    status: Boolean
});


Here, every document in the collection will have a task (string) and status (boolean).

2️⃣ Collection

Definition:
A collection is a grouping of MongoDB documents, similar to a table in SQL. (documents in mongodb = rows in sql)

Collections store documents of a similar type or purpose.

Example:

Todos collection stores all todo items.

MongoDB automatically creates a collection if it doesn’t exist when you insert a document.

3️⃣ Model

Definition:
A model is a compiled version of a schema that provides an interface to interact with the database.

Using a model, you can create, read, update, and delete documents.

Example in Mongoose:

const Todo = mongoose.model('Todo', todoSchema);


Todo is the model, and it is connected to the Todos collection.

4️⃣ Document

Definition:
A document is a single record in a MongoDB collection.

It is represented as a JSON-like object with key-value pairs.

Example document in Todos collection:

{
    _id: ObjectId("652c3d2f1a2b3c4d5e6f7890"),
    task: "Learn Mongoose",
    status: false
}


Each document has a unique _id automatically generated by MongoDB.
